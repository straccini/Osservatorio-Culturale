## 5. Ricerca ANAC — Monitoraggio bandi sotto-soglia

### Problema
TED API copre solo bandi **sopra soglia EU** (≥215K€ per servizi). In Italia la grande maggioranza dei bandi cultura/musei è **sotto soglia** → non monitorati.

### Fonti investigate

| Fonte | Esito |
|-------|-------|
| **ANAC open data** (`dati.anticorruzione.it`) | CKAN 2.6.8 accessibile ma `package_search?q=cultura` → 0 risultati (cerca nomi dataset, non gare). 70 dataset totali, tutti **bulk ZIP** mensili non filtrabili. |
| **ANAC `getSmartCig/{cig}`** | Solo per CIG già noto — a consuntivo, non utile per discovery |
| **ANAC OCDS endpoint** | Bloccato da WAF F5 (risposta HTML "Request Rejected") |
| **BDNCP** `pubblicitalegale.anticorruzione.it` | SPA — API interna non documentata. Endpoint `/swagger-ui.html`, `/api/bandi`, `/pvl-api/v1/avvisi` → 404 o shell HTML. **Da investigare via network inspection** |
| **SCP/MIT** `serviziocontrattipubblici.it` | Pagina home e RSS → HTML principale (nessun feed RSS identificato) |
| **Portali CKAN regionali** | Già integrati; coprono parzialmente il sotto-soglia regionale. Puglia CKAN: 6 risultati confermati |

### Conclusione e prossimo passo

**Fonte corretta**: `pubblicitalegale.anticorruzione.it` (BDNCP — Piattaforma di Pubblicità a Valore Legale).  
Dal 1° gennaio 2024 **tutti** i bandi italiani, anche sotto-soglia, devono pubblicarsi lì.

**Passo successivo**: aprire il portale BDNCP nel browser, effettuare una ricerca per CPV cultura (92xxx), e catturare la chiamata XHR/JSON sottostante con DevTools → se l'API restituisce JSON pulito, costruire un parser GAS compatibile.
